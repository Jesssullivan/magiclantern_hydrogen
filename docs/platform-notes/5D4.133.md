# Canon 5D Mark IV (firmware 1.3.3)

This release of `magiclantern_hydrogen` targets the 5D Mark IV with
factory firmware **1.3.3**. The platform code is `5D4.133`.

## Status

- Experimental platform — ML support on the 5D Mark IV is more recent
  than on 5D2 / 5D3. Capabilities lag behind the 5D3 line.
- `rawspect` emits `RAWX` blocks; gain register reads adapted for Digic
  VI+.
- `aflogger` emits `AFLG` blocks; dual-pixel-specific data via
  `PROP_LV_LENS_STABILIZE` and `PROP_LENS_DYNAMIC_DATA` (DIGIC 8+
  property; absent on 5D4's DIGIC 6+ — surfaced through the availability
  bitmap).

## Sensor

- 30.4 MP full-frame CMOS, RGGB Bayer with Dual Pixel autofocus, 14-bit
  raw.
- Modified bodies have AA filter + full filter stack removed.

## Caveats

- The 5D4 has tighter raw-video timing than 5D3; sustained 14-bit at
  full resolution is not guaranteed. Crop modes recommended for science
  workflows.
- Dual Pixel AF data is exposed through the AFLG block where the relevant
  properties are populated; downstream consumers must check the
  availability bitmap (`MLV_AFLG_HAS_*`) before reading dual-pixel fields.
