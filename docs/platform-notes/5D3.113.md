# Canon 5D Mark III (firmware 1.1.3)

This release of `magiclantern_hydrogen` targets the 5D Mark III with
factory firmware **1.1.3**. The platform code is `5D3.113`.

## Status

- Boots Magic Lantern menus.
- Raw video via `raw_vidx` + MLV.
- `rawspect` emits `RAWX` blocks; analog/digital gain pulled from
  `SHAD_GAIN_REGISTER` (Digic V).
- `aflogger` emits `AFLG` blocks on AF / aperture / IS events; AFMA
  offset surfaced from `PROP_AFMA`.

## Sensor

- 22.3 MP full-frame CMOS, RGGB Bayer, 14-bit raw.
- Modified bodies have AA filter + full filter stack removed.

## Notes specific to 1.1.3

The 5D3 has two ML-supported firmware versions in this fork: `1.1.3`
and `1.2.3`. They share most of the source tree but have distinct
stub addresses; the `1.2.3` tarball is **not** compatible with a
camera running 1.1.3 (and vice versa). Check `Menu → Firm Ver.` before
flashing.

If your camera is on a different Canon firmware, update / downgrade
Canon firmware first using the official Canon update package.
