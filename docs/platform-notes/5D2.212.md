# Canon 5D Mark II (firmware 2.1.2)

This release of `magiclantern_hydrogen` targets the 5D Mark II with
factory firmware **2.1.2**. The platform code is `5D2.212`.

## Status

- Boots Magic Lantern menus.
- Raw video via `raw_vidx` + MLV.
- `rawspect` emits `RAWX` calibration blocks per VIDF (no Digic-V
  `SHAD_GAIN_REGISTER` on this generation; analog/digital-gain
  availability bitmap reports unavailable).
- `aflogger` emits `AFLG` blocks on AF / aperture / IS events.

## Sensor

- 21.1 MP full-frame CMOS, RGGB Bayer, 14-bit raw.
- Modified bodies in this fleet have the AA filter + full filter stack
  removed for narrowband / NIR / spectral work.

## In this tarball

| File | Purpose |
|---|---|
| `autoexec.bin` | ML bootloader. Picked up by Canon firmware at power-on. |
| `ML-SETUP.FIR` | One-time installer (run once via `Menu → Firm Ver.`). |
| `modules/*.mo` | ML modules to enable from `ML menu → Modules`. |
| `MODULES.txt` | Manifest of module names. |
| `INSTALL.md` | Canonical install / recovery / uninstall guide. |

## Install

See `INSTALL.md` in this tarball. Quick version: drop everything onto a
clean FAT32 SD card, run the firmware update once.

## Known issues / quirks

- 5D2's older Digic IV does not expose the per-frame analog-gain register
  that 5D3+ provides; `RAWX` blocks on this platform report analog/digital
  gain as the `MLV_RAWX_HAS_*` sentinel. Reduction pipelines should fall
  back to ISO-derived gain.
- Live-view raw streaming is more bandwidth-limited than 5D3+; expect
  smaller crop regions for sustained 14-bit capture.
