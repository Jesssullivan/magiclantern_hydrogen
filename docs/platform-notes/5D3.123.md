# Canon 5D Mark III (firmware 1.2.3)

This release of `magiclantern_hydrogen` targets the 5D Mark III with
factory firmware **1.2.3**. The platform code is `5D3.123`.

## Status

- Boots Magic Lantern menus.
- Raw video via `raw_vidx` + MLV.
- `rawspect` emits `RAWX` blocks; analog/digital gain pulled from
  `SHAD_GAIN_REGISTER` (Digic V).
- `aflogger` emits `AFLG` blocks on AF / aperture / IS events; AFMA
  offset surfaced from `PROP_AFMA`.

## Sensor

- 22.3 MP full-frame CMOS, RGGB Bayer, 14-bit raw.
- Modified bodies have AA filter + full filter stack removed.

## Notes specific to 1.2.3

`1.2.3` is the more capable of the 5D3 firmwares for raw video: lower
overhead per frame, slightly better sustained throughput. Most of the
upstream ML 5D3 work was done against this firmware.

If your camera is on Canon firmware 1.1.3, either downgrade-impossible
(Canon doesn't allow it cleanly) or use the `5D3.113` tarball.
